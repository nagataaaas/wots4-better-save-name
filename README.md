# セーブ名の改善

[English](README.en.md)

> [!NOTE]
> この Mod は [Steam 版『侍道4』](https://store.steampowered.com/app/312780/4/?l=japanese)専用です。

セーブ・ロード・削除の一覧で、`S4-DATA_01` のようなファイル名の代わりに、そのデータがどこまで進んでいるかを表示します。

## 機能

- **一覧の 1 行目にデータの中身**：スロットの番号、日数と時間帯、直近のイベントを `01: 1日目夜 [外]電信あり` のように表示します。
  - イベントの前の `[攘]`・`[幕]`・`[外]`・`[真]` は、そのイベントがイベントチャートで属するルート（攘夷・幕府・外国・真ルート）です。共通のイベントには付きません。
  - イベント名は、イベントチャートと同じ名前を、ゲームの言語で表示します。
  - 序章のデータは、日数の代わりに「序章」と表示します。
  - 行に収まらない長さのときは文字の幅を詰め、それでも収まらなければイベント名の後ろを「…」で省きます。
- 日時・主人公名・難易度など、ほかの表示は変わりません。セーブ・ロードの動作も変わりません。
- [autosave](https://github.com/nagataaaas/wots4-autosave) と一緒に入れると、オートセーブの行も `AUTOSAVE: 2日目昼 …` のように表示されます。

直近のイベントは、最後に引き受けた、または終えたイベントです。時間帯が進んだあとのデータでは、それまでに引き受けた・終えた・失敗したイベントのうち、いちばん後の段階のものになります。

## インストール

### 自動インストール（推奨）

1. ゲームを終了してください。
2. [WayOfTheSamurai4ModInstaller.exe](https://github.com/nagataaaas/wots4-mods/releases/latest/download/WayOfTheSamurai4ModInstaller.exe) をダウンロードして実行してください。
   - 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください。
   - 管理者として実行してよいかの確認が出たら、「はい」を押してください（ゲームのフォルダに書き込むためです）。
3. 画面の案内に沿って進め、Mod の一覧で `better_save_name` を選んでください。↑↓ で移動し、Space で選び、Enter で確定します。

ModLoader も一緒に入ります。更新も同じ手順でできます。

4. `{侍道4インストールフォルダ}/mods/better_save_name/mod.dll` があることを確認し、ゲームを起動してください。

## アンインストール

1. ゲームを終了してください。
2. `{侍道4インストールフォルダ}/mods/better_save_name/` フォルダを削除してください。

セーブのデータは書き換えないので、削除すると元のファイル名の表示に戻ります。
